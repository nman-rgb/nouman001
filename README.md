# Syed Nouman Jameel — Portfolio

Personal portfolio website for **Syed Nouman Jameel**, Supply Chain & Fulfillment professional based in Dubai, UAE.

Live site: https://nman-rgb.github.io/nouman001/

## Files

- `index.html` — page content
- `styles.css` — styling (dark/light themes, responsive layout)
- `script.js` — theme toggle, mobile menu, scroll animations
- `assets/Syed_Nouman_Jameel_Resume.pdf` — downloadable CV

## Publishing with GitHub Pages

1. Go to **Settings → Pages** in this repository.
2. Under **Build and deployment**, set **Source** to *Deploy from a branch*.
3. Choose the branch that contains these files and the **/ (root)** folder, then **Save**.
4. After a minute, the site is live at the URL above.
